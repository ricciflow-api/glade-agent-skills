# Security policy

Email [contact@gladeapi.com](mailto:contact@gladeapi.com) with the subject
`SECURITY: glade-agent-skills`. Do not open public issues containing a
vulnerability, API key, customer data, or sensitive marketplace query.

Relevant reports include credential leakage, unsafe origin handling,
prompt-injection exposure, missing request bounds, or a skill instruction that
could cause unauthorized or unexpectedly expensive actions.
